# Black Friday Sales Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Black Friday Sales data using Python. The main objective is to understand customer purchasing behavior and identify meaningful patterns based on demographic and product-related factors.

The analysis explores factors such as gender, age, marital status, occupation, product categories, and purchase amount using different data analysis and visualization techniques.

## 📊 Dataset

The Black Friday Sales dataset contains more than 537,000 records and includes information about customers, products, demographics, and purchase amounts.

### Main Columns

* User_ID
* Product_ID
* Gender
* Age
* Occupation
* City_Category
* Stay_In_Current_City_Years
* Marital_Status
* Product_Category_1
* Purchase

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 Analysis Performed

### 1. Dataset Walkthrough

Loaded the dataset and examined its structure, columns, data types, and missing values.

### 2. Column Analysis

Analyzed important columns and their unique values. Missing and unnecessary columns were handled during preprocessing.

### 3. Gender Analysis

Analyzed customer distribution and purchase behavior based on gender.

### 4. Age & Marital Status Analysis

Studied purchasing patterns across different age groups and marital-status categories.

### 5. Multi-Column Analysis

Combined multiple demographic columns to identify more detailed purchasing patterns.

### 6. Occupation & Product Analysis

Explored the relationship between occupation, products, product categories, and purchase behavior.

### 7. Gender & Marital Status Analysis

Analyzed the combined effect of gender and marital status using visualizations.

## 📈 Visualizations

The project uses various visualizations such as:

* Bar Charts
* Count Plots
* Pie Charts
* Distribution Analysis

These visualizations help present the findings in an easy-to-understand manner.

## 💡 Key Insights

* Male customers represent a larger proportion of the purchases in the dataset.
* Different age groups show different purchasing patterns.
* Customer occupation has a noticeable relationship with product purchasing behavior.
* Product categories contribute differently to overall purchase amounts.
* Combining demographic attributes provides deeper insights into customer behavior.

## 🎯 Conclusion

This project demonstrates the practical application of Exploratory Data Analysis using Python. It helped identify purchasing patterns and understand how demographic and product-related factors influence customer purchasing behavior during Black Friday sales.
